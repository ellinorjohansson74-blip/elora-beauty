# Create Article – ÈLORA

## Purpose

Create original beauty articles for the ÈLORA website.

## Instructions

1. Ask the user what the article should be about.

2. Write an original article in English about makeup,
   skincare or natural beauty.

3. Use a warm, professional and inspiring tone.

4. Create a title, introduction, subheadings and paragraphs.

5. Follow the JSON structure in:
   artiklar/test-artikel.json

6. Save the finished article in the artiklar folder
   using a lowercase filename with hyphens.
   Do not use å, ä or ö in the filename.

7. Do not overwrite existing articles.

8. For an article with an image:
   - Save the image in images/.
   - Include an img block in the JSON.
   - Use src and a descriptive alt text.

9. Ask the user to review the article before publication.

10. After approval, add a link to the homepage:
    artikel.html?id=artikelns-filnamn

## Important

- Do not change existing website files without approval.
- Check that the JSON is valid.
- Do not invent image filenames.
- Do not include API keys or passwords.
